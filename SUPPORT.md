# Support

## Getting started

### Installation

```bash
git clone https://github.com/Caezarr/gauntlet
cd gauntlet
npm install
npm run install-browsers
```

### Smoke test

Verify the CLI is working:

```bash
npm run bugfinder -- --help
npm run review -- --help
npm run security -- --help
npm run design -- --help
npm run build -- --help
```

## Bugs and feature requests

Open a [GitHub Issue](https://github.com/Caezarr/gauntlet/issues) with a clear reproduction (command, config snippet, expected vs actual).

## Security vulnerabilities

Report privately via [GitHub Security Advisories](https://github.com/Caezarr/gauntlet/security/advisories/new). See [SECURITY.md](SECURITY.md) for full policy and scope.
